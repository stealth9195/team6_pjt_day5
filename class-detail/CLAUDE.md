# class-detail/CLAUDE.md

이 파일은 클래스 예약 상세 페이지에만 해당하는 규칙이에요.
팀 공통 규칙(말투, 용어, 색, Git, 수정 범위)은 루트 `CLAUDE.md`를 따르고, 여기에는 다시 쓰지 않아요.

## 1. 페이지 개요
- 페이지: 클래스 예약 상세
- 담당: 조아라
- 목적: 클래스 정보를 확인하고 날짜·시간·인원을 골라 예약까지 마치는 페이지
- 들어오는 경로: 목록 페이지에서 카드를 누르면 `?id=c001` 형태로 들어와요

## 2. 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 HTML (`frame.html`을 복사해서 시작). 페이지 전용 스타일은 `<head>`의 `<style>` 안에 |
| `detail.js` | 페이지 동작 (슬라이드, 정보 채우기, 예약 창, 완료 팝업) |

- 스크립트 순서: `../data/classes.js` → `../layout.js` → `detail.js`
- `<body data-page="class">`를 써요 (예약은 클래스 메뉴에서 들어오는 화면)
- 추가 파일이 필요하면 이 폴더 안에 만들어요
- 이 폴더 안의 파일만 수정해요. 공통 파일(공통 틀, 공통 CSS, `data/classes.js`)과 다른 사람 폴더는 수정하지 않아요
- 공통 파일에 필요한 것이 생기면 무엇이 필요한지만 정리해서 알려 줘요

## 3. 데이터
- `data/classes.js`만 사용해요: `<script src="../data/classes.js"></script>` → `window.CLASS_DATA`
- 클래스 찾기: 주소의 `?id=` 값으로 `getClassById(id)`를 불러요
- `id`가 없거나 잘못되면 첫 번째 클래스(`classes[0]`)를 보여 줘요
- 페이지 안에 클래스 데이터를 복사하거나 새로 만들지 않아요. 데이터 수정이 필요하면 데이터 담당자에게 요청해요
- 사용하는 항목

| 화면 | 데이터 |
|---|---|
| 이미지 슬라이드 | `images[]` (`src`: 사진 경로, `alt`: 설명, `credit`: 출처, `color`: 사진을 못 불러올 때 쓸 색 변수 이름) |
| 기본 정보 | `category`, `title`, `host`, `price`, `originalPrice`, `rating`, `reviewCount`, `location.region`, `location.address`, `duration`(분), `level`, `maxPeople` |
| 클래스 소개 | `description` (줄 단위로 읽어 소제목·목록·문단으로 나눠요) |
| 후기 | `reviews[]` (`nickname`, `rating`, `date`, `text`) |
| 예약 창 | `schedule[]` (`date`, `slots[]` → `time`, `remaining`) |

## 4. 화면 구성 (위에서 아래 순서)
1. 이미지 슬라이드
2. 기본 정보
3. 클래스 소개
4. 후기
5. 예약 버튼 (모바일: 화면 아래 고정 / PC: 오른쪽 패널 안)
6. 예약 창 (바텀시트)
7. 완료 팝업

## 5. 레이아웃
- PC: 왼쪽에 이미지·소개·후기, 오른쪽에 기본 정보와 예약 버튼이 있는 정보 패널
- PC 정보 패널은 스크롤해도 화면에 붙어서 따라와요 (sticky)
- 모바일: 위에서 아래로 한 줄 (4번 순서대로). 하단 고정 버튼이 내용을 가리지 않게 본문 아래 여백(safe-area 포함)을 둬요
- PC와 모바일을 나누는 기준 폭: 1024px (`@media (min-width: 64em)`)

## 6. 기능 규칙
### 이미지 슬라이드
- 외부 라이브러리 없이 직접 구현해요
- 사진(`src`)을 `object-fit: cover`로 보여 줘요. 첫 장만 바로 불러오고 나머지는 지연 로딩해요
- 사진을 못 불러오면 사진을 지우고 `background: var(${img.color})` 색 박스에 `alt` 문구를 보여 줘요. 대체 색은 넣지 않아요
- 큰 이미지 아래에 "사진: 작가 / Unsplash" 출처를 보여 주고, 작가 이름은 사진 페이지로 새 창 링크예요
- 이전/다음 버튼, "1 / 5" 위치 표시, 썸네일 목록(현재 썸네일 강조)
- 모바일은 손가락으로 밀어서 넘겨요 (CSS scroll-snap). 키보드 좌우 화살표로도 넘길 수 있어요

### 예약 창
- 캘린더는 외부 라이브러리 없이 직접 구현해요
- `schedule`에 있는 날짜만 고를 수 있어요. 나머지 날짜는 비활성으로 보여 줘요
- 날짜를 고르면 그날의 시간대가 나와요. `remaining`이 0이면 "마감"으로 표시하고 고를 수 없어요
- 인원은 1명부터 고른 시간대의 `remaining`까지 고를 수 있어요
- 결제 금액 = `price` × 인원
- 예약자 정보 입력 항목: 이름, 연락처
  - 둘 다 필수예요. 비어 있으면 결제 버튼을 누를 때 안내 문구를 보여 줘요
  - 입력한 정보는 어디에도 저장하거나 보내지 않아요 (localStorage, 콘솔 출력 포함)
- 예약 창을 여는 방식: 바텀시트
  - 예약하기를 누르면 아래에서 올라오고 뒤 배경은 어두워져요. 열려 있는 동안 뒤 페이지는 스크롤되지 않아요
  - X 버튼, 배경 클릭, Esc 키로 닫혀요
  - PC는 왼쪽 캘린더 / 오른쪽 시간·인원·예약자 정보·금액, 모바일은 위아래로
- 캘린더: 이번 달부터 일정이 있는 달까지만 이동해요. 지난 날짜·일정 없는 날짜는 비활성, 모든 시간대가 마감인 날짜는 "마감"
- 날짜를 바꾸면 시간과 인원 선택을 초기화해요
- [결제하기]는 날짜와 시간을 모두 골라야 활성화돼요

### 결제와 완료 팝업
- 결제 연동은 없어요. 결제 버튼을 누르면 완료 팝업만 띄워요
- 완료 팝업에는 클래스 이름, 날짜, 시간, 인원, 결제 금액을 보여 줘요
- 완료 팝업을 닫은 뒤 동작: 상세 페이지에 머물러요
  - [확인] 또는 Esc를 누르면 팝업과 예약 창이 모두 닫히고, 선택한 날짜·시간·인원과 입력한 이름·연락처를 비워요
  - 닫으면 포커스를 예약 창을 열었던 버튼으로 돌려요
- 예약한 시간대의 남은 자리 수를 화면에서만 줄여요. 다시 열면 반영되고, 새로고침하면 원래대로예요

### 접근성
- 예약 창과 완료 팝업: `role="dialog"`, `aria-modal="true"`, 제목 연결. 열리면 창 안으로 포커스, Tab은 창 안에서만, 닫히면 원래 버튼으로
- 캘린더 날짜는 button이고 "11월 3일, 예약 가능"처럼 읽혀요. 선택한 날짜·시간은 `aria-pressed`
- 금액이 바뀌면 `aria-live`로 알려요. 별점은 "5점 만점에 4.8점"을 스크린 리더용으로 함께 써요
- 움직임 줄이기 설정이면 슬라이드·창 애니메이션을 꺼요

## 7. 디자인
- 공통 CSS와 디자인 문서에 있는 클래스·변수만 사용해요. 색 값(`#색상코드` 등)을 직접 쓰지 않아요
- 필요한 값이나 부품이 공통 CSS에 없으면 새로 만들지 말고 무엇이 필요한지 알려 줘요
- 공통 CSS: `../style.css` (디자인 문서: `freely_co/CLAUDE.md`)
- 공통 CSS에 없는 스타일은 페이지 `<style>` 안에 공통 변수만 써서 만들고, 클래스 이름은 `booking-`으로 시작해요
- 목업 별점에는 정보 패널에만 "예시" 표시를 붙여요 (후기 섹션 제목에는 붙이지 않아요)

## 8. 작업 방식
- 화면 구성 순서대로 한 섹션씩 만들고, 끝날 때마다 바꾼 파일을 알려 줘요
- 브라우저에서 확인하지 않았다면 그 사실을 분명히 말해요
- 작업이 끝나면 CSS에 색 값이 직접 쓰였는지 검색해서 결과를 알려 줘요
